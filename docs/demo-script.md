# AERIS — 3-Minute Demo Video Script

A judge-facing walkthrough. Keep pacing tight; each beat is ~15–20 seconds.

1. **Open Command Center (0:00–0:20)**
   - Show the Next.js Command Center dashboard: live AQI map, station list, current readings.
   - Narrate: "AERIS ingests live air-quality and contextual data across 141 cities in real time — no mock data in the hot path."

2. **Trigger /agents/coordinate (0:20–1:10)**
   - Click "Run Coordination" → `POST /agents/coordinate`.
   - Show the forecast output (ForecastAgent), hotspot detections (HotspotAgent), and SourceAttributionAgent results fusing Sentinel-5P + NASA FIRMS + OSM land-use with a **confidence score** per source.
   - Show multilingual advisories generated by CitizenAdvisoryAgent (VulnerabilityService + LLM).
   - Narrate: "One call orchestrates nine agents — forecasting, hotspotting, satellite+land-use source attribution with confidence, and vulnerability-aware advisories."

3. **Open /evidence (1:10–2:10)**
    - Navigate to the `/evidence` page.
    - Point to the **RMSE vs persistence** evaluation harness (`ml-service/eval_harness.py`) comparing the XGBoost forecast to a naive baseline — note this metric is currently an illustrative placeholder pending the live DB backtest.
    - Point to **attribution confidence** and **signal-to-intervention** metrics.
    - Narrate: "Every claim is verifiable: forecast accuracy is benchmarked against persistence, attribution carries a confidence value, and we trace each signal to a concrete intervention."

4. **Open /advisories (2:10–2:50)**
   - Show the `/advisories` page with **Tamil, Kannada, and Hindi** advisory cards.
   - Highlight vulnerability badges (elderly / child / respiratory risk).
   - Narrate: "Advisories are localized and vulnerability-aware, so the right message reaches the right community."

5. **Close (2:50–3:00)**
   - Recap: innovation (satellite+land-use attribution), business impact (signal-to-intervention), technical excellence (live ingestion + RMSE eval), scalability (141 cities + cached spatial services), UX (multilingual vulnerable-aware cards).
   - End card: "AERIS — verifiable, scalable, judgeable."
